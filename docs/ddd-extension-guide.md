# 原生功能扩展指南

| 要修改的行为 | 修改入口 | 应验证的结果 |
| --- | --- | --- |
| 节点导入或订阅身份 | Kit 映射旧字段与持久化格式，Domain 决定匹配顺序和歧义处理 | 未编辑字段、节点选择、统计和未知记录得到保留 |
| 运行节点、组成员、订阅变更 | 宿主比较实际生成的配置，Application 编排运行替换及补偿 | 等价变更保留会话，生效变更切换到新节点，失败恢复原节点转发 |
| 参数、路由或 DNS | Kit 保存完整快照，复用已有设置事务、监听预检和 Xray 配置生成 | 保存失败、端口占用和配置拒绝都能恢复 |
| 普通代理或 TUN 恢复 | Domain 表达运行意图与事实，Application 编排恢复，Kit 执行系统操作 | 迟到观察不能覆盖新会话，用户关闭后可以取消恢复 |
| 主页与页面跳转 | SwiftUI/AppKit 管理输入与文字，RealityKit 管理场景，PageCubeNavigation 管理页面交接 | 点击时保留当前画面，目标准备好再旋转，减少动态效果和编辑确认照常生效 |
| 特权网络配置 | NativeHelperSession 与 TunHelper 的 XPC 契约及网络租约 | 鉴别签名调用者，用原会话确认恢复，隔离测试先于真实 TUN |

领域规则接受业务值，适配器负责解释 SQLite、旧节点格式和系统响应。跨资源用例应明确何时提交、谁拥有旧会话、哪个步骤可以取消，以及补偿失败时要保留哪些凭据。原生宿主持有同一份操作状态，新增用例复用这份状态。

先运行依赖检查和产品边界检查，再运行受影响的 Swift 测试及签名包回环。与 C# 参考行为有关的变更另跑对应的上游测试。测试入口见 [README](../README.md)，上游代码处理规则见[合并规则](upstream-merge-policy.md)。
