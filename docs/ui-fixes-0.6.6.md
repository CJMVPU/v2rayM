# UI corrections — 0.6.6

The 0.6.5 RealityKit conversion exposed a scroll synchronization bug: surface anchors could enter their immediate parent before SwiftUI attached that parent to a scroll view. Registering the scroll observer only in `viewDidMoveToSuperview` missed that later attachment. Watching only the nearest clip also missed outer vertical scrolling for controls inside a horizontal scroller.

Anchors now rediscover their scroll ancestors during layout and window attachment, observe every enclosing clip, and retire observations when detached. The Settings overview supplies an explicit viewport shared by SwiftUI clipping and the RealityKit scene. This matters because AppKit's hosting scroll view can extend into the window's top safe area even though SwiftUI clips the content below the title bar. Scrolled-off switches and button surfaces can no longer paint over navigation. Empty intersections are rejected before mesh creation, and entities join the scene only after successful creation, preventing orphan entities from fully clipped controls.

The four navigation assets now use simple rounded silhouettes and matte blue/cyan materials: a house without chimney/window detail, a three-node graph, a log slab with three strokes, and a soft six-lobed gear. All retain genuine volume, transparent surroundings, hover/selection turns, disabled handling and Reduce Motion support. The title bar is 26 pt high (previously 32), icons are 22 pt, and the Nodes table starts 8 pt below the title bar. Fixed table column widths and actions remain unchanged.

Module updates always show both progress tracks. Idle and unsuccessful completion show empty tracks, successful completion shows full tracks, downloads show their measured fraction, and active phases without a known total remain indeterminate. The explanatory footer requested for removal is gone. Service errors occupy the existing summary line with a details action, preserving panel height across update states. Core validation and installation policy are unchanged.

Validation includes nested scroll ancestors attached after their child anchors, fully clipped entity retirement, real Settings scrolling to intermediate/bottom/top positions, native action and Chinese input tests, navigation flip cancellation and asset loading, and all update layout states. GPU captures cover all four pages, enlarged assets and three Settings scroll positions. Build, signature, packaged loopback smoke, DMG verification, installed-app preservation and cleanup receipts are recorded separately in `artifacts/reviews/2026-11-18-ui-fixes-066/`.

The full native suite completed 240 tests: 232 passed, 8 opt-in checks skipped, zero failures. Product boundary, DDD dependency and generated helper contract checks passed.

No backend or helper behavior changed. The package is development-signed, not notarized. No real TUN test or sustained GPU power comparison is claimed. The existing installation is preserved, and remote CI is not awaited.
