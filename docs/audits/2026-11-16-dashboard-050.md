# v0.5.0 dashboard traffic presentation

- Display proxy upload/download in cyan/purple and Xray direct upload/download in
  green/orange. Two outer direct rings surround the proxy rings; the five-minute
  trend retains all four independently sampled rates on a common scale.
- Preserve the backend's one-minute rolling averages, stale-sample rejection,
  pause/resume history and segment boundaries. Peaks and retirement scale now
  include direct traffic. Direct means Xray's direct outbound, not all Mac traffic.
- Speed and node-total cells use inline arrow/value pairs. Speed has proxy and
  direct rows; persisted node totals remain proxy-only. Tooltips and accessibility
  labels retain route and direction names.
- Disc hover checks pointer distance against the inset disc radius, excluding
  outer rings and bounding-box corners. Hover still changes only the disc surface.
- Remove the recent-connections heading and display six records. Remove only the
  title-bar import icon, retaining import on the Nodes page and updating DMG help.
- Version rolls from 0.4.9 to 0.5.0; package display and build use VERSION.
