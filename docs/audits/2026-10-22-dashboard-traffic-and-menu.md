# 0.1.16 主页流量、版本与菜单栏

用户截图中代理关闭；本机 EnableStatistics 与 DisplayRealTimeSpeed 均为 true。没有证据表明采集开关丢失，旧主页未区分停用、未采集和无有效采样的原因。

- 主页显示采集状态；保留未采样的“—”，不伪造零速率。仅本地监听状态也可展示有效速率。
- 节点卡片读取 API 已有的 totalUp/totalDown（KiB），格式化累计流量；统计关闭时明确说明。补充协议、运行模式和累计统计状态，减少下方稀疏行距。
- 无效或重置采样不再被转换成有效的全零样本。
- Xray 已安装版本从运行时选择的本机二进制 version 输出读取，2 秒超时，文件路径/长度/修改时间缓存；安装替换后失效。读取失败不显示虚构版本。
- 主页用盾牌状态符号替代电源圆环，不添加点击动作。
- 菜单栏 V：未启用采用系统模板色，系统代理蓝色，原生 TUN 绿色，待确认/切换/异常橙色。使用与主页相同的实际运行状态判定，每秒刷新并更新说明。
- 菜单增加系统代理/TUN 快捷项，复用 AppModel.toggleProxy/toggleTun 与既有互斥事务；实际运行项打勾，离线/操作/更新期间禁用，并在点击时重新检查。NSMenu 关闭自动启用，避免绕过禁用状态。

验证：后端 420 项，原生 46 项；最终签名包回环检查验证实际 Xray 流量、累计计数增长、停止后累计保留、版本号读取。真实系统代理/TUN 切换没有在 v2rayN 接管网络时触发。安装和界面证据见 artifacts/releases/verification-0.1.16。

用户现场确认：展开 V 菜单后，“系统代理”和“TUN 模式”两个快捷项均正常可见、可点击，当前均未勾选。实际开启后的颜色及网络模式切换尚未现场测试；保持 v2rayN 当前网络状态。
