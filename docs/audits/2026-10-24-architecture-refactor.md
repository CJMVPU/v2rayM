# 0.3.3 架构改造验收

本轮覆盖原生端、ServiceLib/WebAPI、签名 helper、构建发布与定位资源。
保留 SwiftUI → 本机认证 WebAPI → ServiceLib → Xray，以及独立特权 helper 的权限边界。
本清单的完成状态以最终测试报告和发布 manifest 为准，不能以代码拆分或构建成功代替行为验收。

## 验收范围

1. **观察与控制隔离**：非关键日志、节点、路由及更新进度失败不停止健康代理；关键快照单独判定连接健康；元数据按需/低频刷新。
2. **连接意图和实际状态分离**：显式 off/system/tun 意图，恢复中能撤销；标题栏与菜单栏同源；可注入 API/时钟/事件源；覆盖旧响应、迟到成功、恢复取消、退出与更新交错。
3. **后端职责与事务**：生命周期服务、配置存储/应用事务、更新协调器有实际职责；锁和租约统一归属；多表恢复原子化；既有 API/数据库与未知字段兼容。
4. **一致构建与 CI**：单一构建入口及组件来源/摘要 manifest；拒绝旧后端混装；核心来源固定并保留 Darwin 修复标识；补齐版本和补丁触发路径；测试先于打包。
5. **精简**：移除无调用地图渲染和专用资源；普通 Profile DTO 取代 ReactiveUI；移除无调用二维码/旧自动启动/窗口适配叶子及依赖；macOS 产品流水线与独立 WebAPI 发布隔离。保留所有旧持久化 ID 和用户数据。
6. **契约**：更新决策区分 current/available/awaiting-validation/failed，单项和批量共用；严格解析发布版本；helper 跨语言契约/版本/golden 测试；移除无 Xray 用途的 SRS 资源白名单。
7. **性能**：helper 探测缓存、并发合并和失效策略，启动关键预检查实时执行；Geo 定位数据基准测量和格式优化，保持离线 IPv4/IPv6 查询一致性、损坏降级及许可归属。

## 发布要求

- `VERSION`、显示版本和 bundle build 一致，目标 0.3.3。
- 运行产品边界、原生/后端/ServiceLib/helper/契约/构建脚本测试及本地签名包回环检查。
- 从最终源码生成可核对的发布 manifest，并提交全部本轮源码改动。
- 备份现有安装，安装同一验证产物；核对应用/核心/后端/helper 摘要及启动状态。
- 对比安装前后的系统代理、默认路由和 v2rayN 进程，保持其他应用配置不变。
- 真实 TUN 与休眠/Wi-Fi 实网验收、Developer ID、公证分别记录，不借隔离测试宣称通过。

## 已完成的代码与本地验证

- 观察调度与连接意图独立，原生 API、进程、系统代理、时钟及网络事件可注入。原生编排覆盖观察失败、后端退出、迟到状态、恢复与更新交错。
- 生命周期、配置事务、配置存储及模块更新已分离，配置恢复使用三表 SQLite 事务和可重放的跨文件 journal。
- 更新决策及严格发布版本解析统一；helper 使用生成契约和 golden fixture，移除 SRS 白名单，观察探测缓存与关键实时探测分开。
- 删除旧地图绘制及纹理、ReactiveUI/二维码/扫码/旧自动启动/窗口适配和无调用事件/PAC 路径。ServiceLib 已解析依赖由 36 项降到 15 项。保留持久化字段、节点编号和现有记录。
- `places.bin` 与原 JSON 的 559,715 条记录逐条对比一致；定位数据输入与生成结果均有摘要校验。
- Swift 80 项（含 8 项 AppModel 编排及 2 项离线渲染）、WebAPI 447 项、ServiceLib 113 项、helper 35 项、构建来源 11 项测试通过；产品边界、生成契约及 Geo 摘要校验通过。
- 统一构建入口拒绝不同源码或被改写的后端、未验证的 Xray/M1 内核及已移除依赖回流。源码、工具链、输入和签名后产物分别记录摘要。

签名包、回环、安装和网络状态证据输出到本机 `artifacts/releases/verification-0.3.3/`。
该目录不纳入 Git；以 `product/verification.json`、`product/product-manifest.json` 及安装回执为实际验收依据。
真实 TUN/休眠/Wi-Fi 实网、Intel 执行、Developer ID 和公证不属于本次隔离测试结论。

城市表从 44,516,340 字节减至 21,905,232 字节（减少 50.79%）。本机 debug 单次加载对比为 JSON 全解码 493.60 ms、二进制映射及首查 0.308 ms；这不是冷缓存或 RSS 基准，不推导整个应用启动同倍率提升。
