# 0.4.7 异步状态与稳定布局

模块更新行过去按状态插入进度条、版本、百分比和错误全文，更新结束后还留下满格进度条。
在同一实际 SwiftUI 布局测试中，旧实现从 306 点增至 330 点，失败时增至 360 点，推动后续卡片。

- 更新行使用固定列宽、固定行高与预留进度区域；仅进行中的任务绘制进度，结束后隐藏。
- 更新按钮文字保持固定；状态与错误摘要限行，完整内容可通过“详情”浮层查看和复制。
- 登录项批准状态复用原有副标题，保存指示器和重连按钮预留位置。
- DNS 模式、监听端口及 TUN 授权提示保持占位；标题栏恢复代理复用系统代理控件的位置。
- 首页重连按钮不再推动圆盘内的节点和时长信息。通知覆盖层、固定节点页脚和流量图原有布局保留。
- 补回节点导入和编辑的主窗口显示分支；返回导入时确认放弃内容。
  服务断开不会卸载正在编辑的设置草稿，节点编辑离线时禁止保存。

新增实际 NSHostingView 尺寸回归，覆盖九种模块更新状态、登录项授权、保存指示器、
DNS 模式及运行中端口提示。新测试在旧更新面板上复现七种状态的尺寸变化，修复后通过；
同时检查闲置、下载、完成和长错误状态渲染。所有改动限于原生界面及其测试，未更改更新执行、
核心替换或签名授权逻辑。

本地测试、构建、签名、安装及清理证据保存在 `artifacts/reviews/2026-11-15-layout-047/`。
按用户要求，推送后不等待远程 CI；真实 TUN 网络验收与本地打包回环验证分别记录。
