# 0.3.6 最终收敛与长期使用基线

本轮以 `064bd998`（0.3.5）为基线，工作区原本干净。范围为日志刷新、数据保留、更新提交边界、构建来源与维护文档。保留 SwiftUI + Xray、签名 helper、可信更新、网络恢复和未知节点记录边界。此次没有更换 Xray、依赖或 Geo 输入，不将“长期使用”描述为所有网络环境已经验收。

## 修复与交叉审查

- 日志增加约 220 ms 的平滑末尾跟随。仅贴底或尚在跟随时响应追加，快速刷新合并目标；手动滚轮/键盘/选区滚动中断动画。保留横向偏移与按实际高度补偿的旧记录淘汰；减少动态效果直接定位，拆卸视图停止定时器。
- SQLite 异步连接恢复操作级互斥，避免另一个写入混入事务并随其回滚。独立临时数据库的屏障回归已复现“成功写入却一起回滚”，修复后独立写入保留。
- 订阅更新先确认成功导入，再替换旧的已支持订阅节点。无效响应不得清空原节点；未知/不支持记录与同组手动节点保留，自定义文件删除与记录范围一致，仍被其他节点引用的文件保留。完成新节点、统计和配置保存后才删除旧行；找不到替代项的当前节点保留，避免悬空选择。
- 可信更新已提交后，迟到回滚明确拒绝，保留 current；不把丢失回复当作尚未提交。后端报告“已提交保留、最终确认中断”，不猜测已经恢复旧版或核心健康。
- 整包校验重新核对 GeoIP/GeoSite DAT 摘要，并要求两项完整存在；最终 Info.plist 的显示版本与构建版本也重新检查。来源、签名和回环是独立门槛。
- 修复独立签名自检漏编译生成契约的问题；真实 Apple Team ID、ad-hoc 拒绝和相对启动路径三项检查通过。
- README 收敛为安装使用、构建验证及维护入口；删除已退役地图说明与五份被后续修复覆盖的旧审查文档。TUN 文档删除旧多内核历史说明，修复补丁命令中已移除的参数；原文保留在 Git 历史。

## 保留的使用与验收边界

当前本机包为 Apple Development 签名，未公证。新 Xray 版本仍须单独兼容验证，不因上游版本较高自动替换。
另一个 v2rayN 正在接管 TUN/系统代理，本轮不进行真实 TUN 接管，不改变其进程或配置。自动回归和回环无法替代休眠、切网、长时间运行及强制退出后的实机网络验收。

安装时保留 0.3.5 作为唯一上一版回退应用。只删除工作区中清单列出的旧产物，不清理应用数据、系统代理恢复文件或 root 可信内核存储。无需回退时可另行清理上一版；不要把恢复证据当作普通缓存删除。
