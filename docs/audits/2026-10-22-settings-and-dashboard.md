# 0.1.13 设置与代理状态检查

范围：SwiftUI 主页、参数/路由/DNS 编辑器，WebAPI 设置事务、代理切换、日志保留、Xray 入站/DNS 生成和流量采样。保留 Xray-only 边界；本次不修改用户节点、路由方案或系统代理，不接管正在由 v2rayN 使用的 TUN。

## 修复

| 问题 | 修改与验证 |
| --- | --- |
| 路由“新增”保留旧 routeID，可能覆盖旧方案 | 新草稿重置标识、活动状态与规则。原生草稿测试及打包后新增路由/原记录保持测试。 |
| TUN 与本地监听共用 sniffing 对象 | 深复制后再固定 TUN 的 routeOnly；生成配置测试同时断言本地监听未被修改。 |
| 自定义 DNS 仍被普通 FakeDNS 开关影响 | 只有常规 DNS 生效时才自动加入 FakeDNS 嗅探；系统代理与 TUN 均有生成配置回归。 |
| 独立 LAN 端口只填写一半认证信息会退化为无认证 | 两个设置写入口都拒绝半填；界面仅在 LAN 独立端口启用时允许编辑认证信息。 |
| UI 保存后保留未经后端规范化的草稿 | 保存参数后重新读取已保存参数和 TUN 设置。 |
| 流量计数器重置可能产生负上行；固定按一秒解释不准确 | 检查四个计数器重置，按 Stopwatch 实际采样间隔提供速率；数据过期不显示旧速率。 |
| 仅实时显示也累计节点流量 | 不启用累计统计时只发布采样，不创建或增加累计记录；独立回归检查。 |
| 统计采集器快速关闭后可能在异步启动时重新创建取消源 | 构造时建立单一取消源；关闭只取消，任务退出再释放。 |
| helper 内核来源固定宣称随包版本 | 改为 helper-verified-xray，兼容随包签名与可信官方更新，不虚报具体发行来源。 |

## 设置项整理

- 移除“阻止 HTTPS/SVCB 查询”：当前 Xray 配置生成器没有消费此选项，保留磁盘旧值以兼容已有数据。
- 隐藏当前 Mac 界面没有对应操作的去重偏好、IP 信息接口、UDP 测试目标；不清除底层已有值。
- LAN 认证、日志等级、分片参数、FakeDNS 范围体现父开关依赖。
- 常规 DNS 与自定义 DNS 是两种生效模式；明确自定义优先，保留分开保存及脏数据保护。
- 全局默认域名策略与方案策略是继承关系；明确方案覆盖，不合并成会丢失覆盖能力的单字段。
- 系统代理 DNS 与原生 TUN DNS 保持独立；TUN 系统网关/DNS 恢复仍由 helper 管理。
- 路由方案快捷按钮保持同一行，方案增多时可横向滚动且不显示滚动条。

## 主页

固定紧凑布局：状态环、本次运行时长、Mac → Xray → 节点路径、代理/直连上下行四块流量、节点/路由/服务器/传输安全/历史延迟，以及监听端口与 helper 就绪状态。

运行中、关闭、故障、操作中、更新中、本地服务离线、采样/状态过期分别展示；内核运行并不等于已配置系统代理，状态图示不声称外网可达。延迟明确为最近测得，未采样流量显示“—”，不补造数据。保持 LXGWWenKaiMono Medium、860×600 固定窗口与标题栏入口。
