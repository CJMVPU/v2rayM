# v0.5.2 dashboard alignment, dark appearance and motion

- Speed and node totals use common icon/number/unit columns. Numbers and units
  align independently to the right; all values have one decimal place, shared
  14-point text and fixed 14-point arrow geometry. Proxy-only cumulative accounting
  is unchanged.
- Force dark appearance for the app and window, with fixed dark dashboard colors.
  The homepage remains dark when its host requests light appearance.
- Animate disc duration digits. On core activation, flip the inner disc and
  recent-connections card; keep ring geometry fixed. Honor Reduce Motion.
- Before the first valid sample, replace the active waiting label with four colored
  start dots. They do not add synthetic samples or contribute to rates/peaks.
- Center the six connection rows with equal card insets. Update stable row slots
  with vertical flips, swapping at the edge and cancelling obsolete updates.
  Metadata-only changes do not flip connection identities.
